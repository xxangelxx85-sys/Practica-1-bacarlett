Guía de Desarrollo Web y Metodología UWE

Aplicaciones Web Metodología Web UWE y Componentes Conclusiones

1. ¿Qué es una aplicación web?

Definición: Sistema de Información donde datos volátiles y estructurados se procesan y analizan mediante navegadores.

Característica principal: Alto grado de interacción con el usuario e interfaz orientativa, simple y clara.

1.1 Tipos de aplicación web

Se clasifican principalmente según su intencionalidad:

Tipo de Aplicación Intencionalidad / Descripción
Informacionales Difusión de información personalizada o no.
Orientadas a la descarga de datos Servidores de material didáctico o música.
Interactivas Enfocadas en la interacción activa con el usuario.
Orientadas al Servicio Simuladores o asistencia financiera.
Transaccionales Comercio electrónico y banca en línea.
De Flujo de Datos Planificación en línea y control de inventarios.
Entornos de Trabajo Colaborativo Herramientas de diseño colaborativo.
Comunidades on-line (C2C) Foros y subastas.
Portales Web Centros comerciales en línea.
Orientados al análisis de datos Data warehousing y OLAP.

1.2 Características de una aplicación web

  • Usuario: Accesibilidad universal para todo nivel de habilidad.
  • Plataforma: Uso intensivo de red y acceso multidispositivo.
  • Información: Fuentes de datos heterogéneas (estructuradas y no estructuradas).

1.3 Requisitos del desarrollo de una aplicación web

  • Portabilidad: Adaptación a diversas plataformas, arquitecturas y tecnologías mediante la reutilización.
  • Inmediatez: Períodos de implantación muy reducidos.
  • Creación de contenidos: Integrada en la fase de ingeniería.

1.4 Requisitos para la aplicación de una aplicación web

  • Evolución orgánica: Rápida evolución de contenidos y requerimientos.
  • Seguridad en la comunicación: Protección de datos sensibles transmitidos por la red.
  • Velocidad: Selección adecuada de protocolos para garantizar rápido acceso.
  • Importancia de la interfaz: Diseños intuitivos para el usuario.
  • Necesidad de personalización: Aporta valor añadido y retiene usuarios.

2. ¿El por qué de una metodología de desarrollo web?

  • Nace para solucionar la falta de estándares, seguridad, fiabilidad, escalabilidad y mantenimiento.
  • Sustituye el caos de los procesos creativos informales por un proceso sistemático para garantizar la calidad.

3. ¿Qué es UWE?

  • Metodología presentada por Nora Koch en el año 2000.
  • Basada en UML y el Proceso Unificado (UP).
  • Orientada a objetos y al usuario, especializada en aplicaciones adaptativas y personalizadas.

3.1 Principales aspectos

  • Notación estándar: Uso de UML.
  • Definición de métodos: Guías paso a paso para construir modelos.
  • Especificación de restricciones: Uso de OCL (Object Constraint Language) para mayor precisión.

3.2 Principal característica

Enfoque basado en estándares que integra UML, XMI, MOF, MDA, QVT y XML.

3.3 Fases

  • Captura, análisis y especificación de requisitos: Recopila requerimientos funcionales y no funcionales mediante casos de uso, glosarios y prototipado.
  • Diseño del sistema: Define la estructura de la aplicación para cumplir los requisitos.
  • Codificación del software: Traducción del diseño a código fuente.
  • Pruebas: Verificación del correcto funcionamiento del código.
  • Instalación o Implementación: Transferencia, configuración y despliegue del sistema en el entorno destino.
  • Mantenimiento: Control, corrección de errores, mejora y optimización posterior.

3.4 Pasos a realizar

  • Planificación: Diagnóstico participativo, inventario y recolección de información.
  • Diseño: Toma de decisiones de arquitectura y usabilidad.
  • Usabilidad y Accesibilidad: Reducción de costos de aprendizaje/ayuda y mejora de la satisfacción.
  • Prototipado: Modelado visual de la interfaz gráfica.
  • Implementación y Lanzamiento: Uso de estándares (HTML, XHTML) y control de calidad antes de la puesta en marcha.
  • Mantenimiento y Seguimiento: Actualización continua y retroalimentación con los usuarios.
